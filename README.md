# GISOC Consultores - Landing Definitiva
Landing premium creada para GISOC - Consultoría Social para Proyectos de Inversión

## Stack
- HTML5 + Tailwind CSS (CDN)
- Vanilla JS (contadores, FAQ, header blur, form)
- Lucide Icons
- Imágenes documentales de terreno (6) en /assets

## Estructura
- index.html -> Landing completa (11 secciones)
- /assets -> 6 imágenes webp optimizadas:
  - rural_chile_community_meeting.webp (Hero / Reunión participativa)
  - atacama_copper_mine.webp (Minería)
  - patagonian_wind_farm.webp (Energía)
  - san_antonio_port_terminal.webp (Infraestructura)
  - salmon_farm_fjord.webp (Acuicultura)
  - fieldwork_map_collaboration.webp (Metodología / Terreno)

## Para trabajar en VSCode
1. Abre la carpeta gisoc-landing-vscode en VSCode
2. Instala extensión "Live Server" y dale "Go Live" en index.html
3. Edita textos directamente en index.html (busca <!-- HERO -->, <!-- SECTORES -->, etc.)
4. Reemplaza imágenes en /assets manteniendo mismo nombre o actualiza src en HTML
